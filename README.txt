Sunrise Hotel Booking System
Run: copy this folder into htdocs (XAMPP) or www (WAMP), start Apache, open http://localhost/HotelRoomBooking/index.html
Individual requirement (last digit 7): Extra bed option, KSh 1,500 per night (script.js and process_booking.php).
Rates: edit ROOMS / constants at the top of script.js AND process_booking.php.
